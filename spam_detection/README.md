# 📧 Email Spam Detection System

This project detects whether an email is spam or not using machine learning.

---

## 📊 Features

- Word Count
- Number of Links
- Attachments
- Capital Ratio
- Exclamation Count
- Known Sender

---

## 🤖 Model

- Logistic Regression
- StandardScaler
- Stratified Train-Test Split

---

## 📈 Outputs

- Spam Distribution
- Feature Histograms
- Confusion Matrix
- Feature Importance

All outputs saved in `/outputs`

---

## 🚀 Run

```bash
python spam_model.py
